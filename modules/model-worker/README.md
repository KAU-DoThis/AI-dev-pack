# model-worker

Jeff·sLM을 SQS 큐로 연결하는 코드. 두 부분으로 되어 있다.

- **워커**: 모델이 있는 PC에서 돈다. 자기 요청 큐에서 요청을 꺼내 같은 PC의 모델(jeff-serve·vLLM)에 묻고, 답을 결과 큐에 넣는다.
- **클라이언트**: AI 서버가 쓴다. 요청 큐에 넣고 결과 큐에서 자기 답을 받는다.

AI 서버와 모델 PC는 직접 연결되지 않고 큐로만 주고받는다. 워커 코드는 하나이고, PC마다 `.env`만 다르게 쓴다 (Jeff PC는 Jeff 큐, sLM PC는 sLM 큐).

지금은 폴더 자리만 있다. 코드·실행 방법·`docs/model-worker.md`는 다음 커밋에 넣는다.
